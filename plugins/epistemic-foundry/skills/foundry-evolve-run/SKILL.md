# Evolution run

Verify dependencies, expected state revision, evaluator hash, holdout ACL, budget and sequential-testing ledger. Reconcile proposed/evaluated/persisted/failed counts. Run multi-objective quality-diversity selection, Red Queen challenges, hidden validation and checkpointing. Stop on any hard integrity, leakage, safety or authority failure.
