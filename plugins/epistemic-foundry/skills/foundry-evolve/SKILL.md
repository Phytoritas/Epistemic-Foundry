# Evolution Chamber router

Classify whether open-ended search is justified. Freeze an EvolutionRunSpec and evaluator bundle before candidate generation. Load only the minimum child skills. Evolution may propose, mutate, challenge and rank; it cannot promote, alter current evaluators, read hidden holdouts, or erase negative memory.
