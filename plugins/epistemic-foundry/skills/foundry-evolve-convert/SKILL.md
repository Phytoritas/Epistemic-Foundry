# Evolution conversion

Snapshot source bytes and map candidates, scores, correctness, parentage, islands, prompts, evaluator, and results into Foundry contracts. Preserve unmappable fields and semantic gaps. Never reinterpret a raw optimization score as scientific support. For Shinka, require an exact backend manifest and qualification profile.
