# Epistemic Quality-Diversity Archive

## 1. Purpose

The archive is scientific memory, not a leaderboard. It must retain useful differences and costly failures.

## 2. Entry classes

- `elite`: non-dominated stable candidate in a niche;
- `diverse`: valuable alternative trade-off;
- `null`: well-tested no-effect result;
- `counterexample`: reproducible failure or boundary;
- `failed_replication`: prior candidate that did not reproduce;
- `minority_lineage`: grounded dissent not resolved;
- `unsafe`: candidate retained to prevent rediscovery;
- `superseded`: historically valid but replaced revision.

## 3. Niche axes

Core axes:

- mechanism family;
- scope;
- evidence state;
- testability;
- causal status.

Optional DomainPack axes include method, scale, cost, intervention class, jurisdiction, phenotype, material class or algorithm family.

## 4. Replacement

An entry is replaced only when:

- hard gates pass;
- niche assignment is comparable;
- Pareto superiority is robust to uncertainty;
- stability/replication meets the niche policy;
- protected memory is not erased;
- lineage diversity does not collapse;
- an ArchiveRebalancePlan is independently audited.

## 5. Migration

Cross-island transfer requires scope/measurement/unit/causal compatibility. Migration creates a new candidate revision and preserves source island, target island, rationale and outcome.

## 6. Staleness

Ontology, DomainPack, measurement contract or evidence update can make niche assignment stale. Recompute projections from canonical entries; do not mutate historical snapshots.
