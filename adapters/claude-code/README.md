# Claude Code adapter

The adapter binds the host-visible `.claude/agents` files to the same RoleSpec registry; files under the adapter source directory are not treated as the installed Claude surface. The main session remains the research governor. Read-only roles use restricted tools; write-capable roles require isolated worktrees and disjoint write scopes. Results return through the same ResultEnvelope and ledger as Codex.

Host-specific convenience never changes FORGE transition or epistemic promotion semantics.
