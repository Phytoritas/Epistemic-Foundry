# Hypothesis Passport

Report epistemic, causal, novelty, promotion, lifecycle, stability, and confidence-vector dimensions separately. Include supporting/opposing/boundary/null evidence, strongest objection, minority report, searched/unsearched scope, next discriminating test, and complete provenance.
