# Reference blueprint only

This is not an implemented production plugin.

This folder demonstrates the target package layout, manifest, skill metadata and hook registrations. The `dist` and CLI files intentionally exit with code 78 and state that the production runtime is absent. Do not publish or install this folder as a working plugin.

Implementation must be completed through the A–Z development manifest and pass `PLUGIN_ALPHA` gates before the status changes from `REFERENCE_BLUEPRINT`.
